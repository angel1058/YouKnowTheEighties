\# Output Formatting Rule



\- \*\*Do not use LaTeX\*\* or math syntax delimiters (like `$`, `$$`, `\\\[`, `\\\\]`, or `\\begin{equation}`).

\- Write out mathematical formulas using plain text, standard Markdown notation, unicode characters (e.g., θ, π, √, ², ÷, ±), or plain code blocks instead.
