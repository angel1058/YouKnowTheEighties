Render Throttling Mode:

Explanation

Decoupled Mode (Recommended): Game logic ticks independently in a fixed or high-frequency accumulator loop, while DOM screen updates are handled strictly by requestAnimationFrame. The screen never renders faster than the monitor can display, keeping animation smooth regardless of whether UPS is 10 or 10,000.

Naive Mode (Anti-Pattern): Calls DOM render on every single logic update. When UPS exceeds 100+, this floods the browser with DOM reflows and string allocations, killing refresh quality and dropping FPS.
